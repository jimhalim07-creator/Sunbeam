☀️ Sunbeam setup

Put the planner on GitHub Pages, then link it to your Outlook calendar and email. Type your details once and every URL and command below fills in.

The files you upload

Everything in E:\Sunbeam goes in the repository, exactly as laid out here. index.html must sit at the top level.

index.html ← the planner page auth-redirect.html ← Microsoft returns here after sign-in config.js ← your Microsoft client ID goes here README.md ← instructions shown on GitHub .gitignore assets/ css/styles.css js/app.js ← planner logic js/outlook.js ← Microsoft sign-in + calendar/email js/sound.js ← chimes

Leave out setup-guide.html (this page). It's only for you, and git already ignores it.

  2. Upload the files one of two ways:

Register Sunbeam with Microsoft

    
Sign in with your work account (@cef-eg.org) at Microsoft Entra → App registrations and click + New registration.

    

      
FieldEnter

      
NameSunbeam Planner

      
Supported account typesAccounts in this organizational directory only (single tenant)

      
Redirect URI → platformSingle-page application (SPA). Not "Web"; that type causes error AADSTS9002326.

      
Redirect URI → value

    

    
Click Register. On the Overview page, copy two values:

    
    
      
  • Application (client) ID: you'll paste it in step 6.
    • 
      
  • Directory (tenant) ID: optional. Your domain cef-eg.org works in its place.
    • 
    

    
If you see "You do not have access to create applications", your organisation only lets admins register apps. Send your IT admin steps 4–5 of this page, or ask them to register it and give you the client ID.

  


  

    
Give it calendar and email permissions

    
    
      
  1. In the app registration, open API permissions → + Add a permission → Microsoft Graph → Delegated permissions.
    2. 
      
  2. Search for and tick Calendars.ReadWrite and Mail.Send, then click Add permissions. User.Read is already there.
    3. 
      
  3. If you're an admin, click Grant admin consent for <your organisation>. If you aren't, you can try signing in first; many organisations allow users to approve these permissions themselves.
    4. 
    

    
Delegated permissions only let Sunbeam act as you while you're signed in: your own calendar, and email sent from your own mailbox. It can't read your inbox.

Connect in the app

    
    
      
  1. Open your site. Wait a minute after pushing, then press Ctrl+F5 to load the new config.js.
    2. 
      
  2. Go to the Outlook tab and click Connect Microsoft account.
    3. 
      
  3. A popup asks you to sign in and approve the permissions. Click Accept.
    4. 
      
  4. The badge turns green: Connected · you@cef-eg.org.
    5. 
      
  5. Try it: add a plan with Add to my Outlook calendar ticked and check that it appears in Outlook. Click Send now to email yourself today's plan, and Import Outlook events to pull in your meetings.
    6. 
      
  6. Optional: tick Import on startup. Under Reminders, click Enable desktop alerts.
    7. 
    

  


  


  

    
🧰 If something goes wrong

    

      
You seeFix

      
Nothing happens / "popup blocked"Allow popups for your github.io site (icon at the right of the address bar), then click Connect again.

      
AADSTS50011 redirect URI mismatchThe redirect URI in Entra must match exactly, including /auth-redirect.html and lowercase letters. Copy it from step 4, or from the app's Outlook → One-time setup box.

      
AADSTS50194 not configured as multi-tenantSet authority in config.js to https://login.microsoftonline.com/cef-eg.org (step 6).

      
AADSTS9002326 cross-origin token redemptionThe redirect URI was added under "Web". Remove it and add it again under Single-page application.

      
"Need admin approval"Your organisation blocks user consent. An admin opens the app registration → API permissions → Grant admin consent.

      
"Setup needed" even though you edited config.jsThe browser cached the old file. Press Ctrl+F5, or wait a minute for GitHub Pages to redeploy.

      
Email fails with 403Mail.Send is missing or wasn't consented. Add it (step 5), then sign out and connect again in Sunbeam.
